# Тема 8. Функціональне програмування та вбудовані модулі Python

Для запуску потрібен Python 3.10 або новіший. Усі команди виконуйте з кореня репозиторію `goit-pycore-hw-05`.

## 1. Числа Фібоначчі з кешем

`caching_fibonacci()` створює рекурсивну функцію. Вона зберігає обчислені значення між викликами й повертає `0` для цілих `n <= 0`.

```bash
python3 task_1.py
```

Скрипт виводить `55` і `610` для `n = 10` та `n = 15` відповідно.

## 2. Сума доходу з тексту

`generator_numbers(text)` послідовно повертає числа, оточені пробільними символами з обох боків. Десяткова частина відокремлюється крапкою. `sum_profit(text, func)` підсумовує числа, повернені переданою функцією.

```bash
python3 task_2.py
```

Для `1000.01`, `27.45` і `324.00` скрипт виводить `Загальний дохід: 1351.46`.

## 3. Аналізатор логів

Записи у файлі UTF-8 мають формат `YYYY-MM-DD HH:MM:SS LEVEL повідомлення`. Підтримуються рівні `DEBUG`, `INFO`, `WARNING`, `ERROR` і `CRITICAL`. Введіть шлях, щоб отримати таблицю за всіма рівнями у файлі. Додатковий аргумент без урахування регістру показує деталі вибраного рівня під таблицею.

```bash
printf '2024-01-22 08:30:00 INFO Application started\n2024-01-22 09:00:00 ERROR Database connection failed\n' > app.log
python3 task_3.py app.log
python3 task_3.py app.log error
```

```text
Рівень логування | Кількість
-----------------+----------
INFO             |         1
ERROR            |         1

Деталі логів для рівня ERROR:
2024-01-22 09:00:00 — Database connection failed
```

Порожні рядки пропускаються. Якщо рядок пошкоджено, скрипт завершується з повідомленням і номером рядка. Якщо файл недоступний або рівень фільтра невідомий, скрипт показує причину помилки.

## 4. Бот контактів з обробкою помилок

`input_error` перехоплює `KeyError`, `IndexError` і `ValueError` в обробниках команд та повертає підказку. Після помилки бот продовжує роботу.

```bash
python3 task_4.py
```

Команда `hello` вітається. `add John 123456` додає контакт, `change John 654321` оновлює номер, `phone John` показує номер, а `all` показує збережені контакти. `close` або `exit` завершують сеанс. Контакти живуть у пам’яті протягом сеансу.

```text
Welcome to the assistant bot!
Enter a command: add John
Give me name and phone please.
Enter a command: phone
Enter a contact name.
Enter a command: phone John
Contact not found.
Enter a command: exit
Good bye!
```
